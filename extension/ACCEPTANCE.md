## 自动化与构建

- 原生分支协调：连续追问复用同一上下文、父子来源、临时地址转为真实会话地址、重启不重发、并行请求保护、清空/恢复任务隔离。
- 实际 React 卡片：展开、发送、回答显示、收起/重开、子卡片、目录定位，且原生回答 HTML、来源链接、主线输入框身份和值保留。
- 导入与备份：树关系、草稿、折叠状态和上下文地址往返；过滤跨源地址、孤立节点与循环。
- 执行最终生产 content script 和 service worker，检查无 Node 全局对象时启动、新旧 ChatGPT DOM、行内卡片和关闭侧栏后的折叠交互。
- `pnpm test`、`pnpm lint`、`pnpm build`、`pnpm extension:build`。

本地演示的回答明确标记为模拟数据，用于界面交互检查，不作为模型或原生上下文能力的证明。0.2.0 当时的重启恢复主要由自动化覆盖；0.3.0 已补充真实浏览器中父、子支线历史恢复的验证。

## 原型边界

复杂原生内容与 agent 确认继续在对应原生分支标签页操作。后台标签页节流、登录/确认窗口、历史虚拟化以及未来 ChatGPT DOM 变动仍可能需要打开原生页或更新适配器。此轮没有执行真实 agent 任务、附件上传或深度研究验收。
